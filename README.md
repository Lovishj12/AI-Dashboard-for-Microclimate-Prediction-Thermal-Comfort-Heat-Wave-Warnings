# AI-Based Microclimate & Thermal Comfort Dashboard
Bachelor Thesis Project (BTP) — Under the supervision of **Prof. Chirodeep Bakli**

## Project Overview
This project develops an explainable, research-grade microclimate analysis and early warning dashboard for heat stress and heat waves. It links fundamental thermodynamics (psychrometric chart, wet-bulb temperature, heat index, WBGT) with machine learning forecasting and official meteorological warning criteria (IMD, NOAA, OSHA).
